STEP-0:
		1.Download Vs code first or any optional IDE 
		2.open terminal in vs code and direct to your project folder and run venv scripts first
		3.before that must install python 3.13.7 version other wise you will get conflict errors
		4.also install ollama  from source https://ollama.com/download
		5.pull the model llama3.2:1b using with command-{ollama pull llama3.2:1b}
		6.after pulling check the status with this command-{ollama list}
		7.after verfication the status if downloaded run this command -{ollama run llama3.2:1b}
		8.check running instances of ollama with this command -{tasklist | findstr ollama}
		9.if you wanna check which models are currently loaded by Ollama- {ollama ps}
	   10.if installed then run the command -{pip install -r requirements.txt}
	   11.after successfully installation of requirements and followed above steps you may run the app with the command -{python gradio_app.py} 

STEP-1: 							
		1.Create a AWS Account {free tier or optional}
		2.Navigate to console search bar search for IAM 
		3.create an IAM user with your credientials
		4.apply the policies in the policies.png {ignore the inline policies}; apply the policies as direct apply policies
		5.check the policies if any policy contains json as EFFECT = DENY then remove the policy or give it to chatgpt to get inline policy

step-2:
		1.click search in console and navigate to the s3
		2.navigate to buckets and then click create a bucket
		3.give it a name and ignore all the defaults same 
		4.click create a bucket
		5.click on your bucket name and add your source folders and files as per your requirements

STEP-3:
		1.Navigate to Bedrock by searching in the console
		2.on left sidebar navigate to knowledge base
		3.click knowledge base and click create knowledge base and then create knowledge base with vector store
		4.create knowledge base with your friendly name and use data source as s3 
		5.in IAM permission box click "Create and use a new service role"
		6.click next and put data source name as your wish
		7.browse your s3 data source in s3 uri
		8.i choose phraser as Amazon Bedrock default parse you choose your self based on your requirement
		9.and Chunking strategy as default 
	   10.click emmbeding model as "Titan Text Embeddings V2  v2.0"
	   11.click the vector store and in dropdown menu choose s3 vector store
	   12.review everything and click on create knowledge base
	   13.test the knowledge base using the  test

step-4:
		1.open vs-code and clone the repo and give your credientials in .env file
		2.open terminal and type this command -{python -m venv venv}
		3.activate the virtual env with command in powershell -{.\venv\Scripts\activate}
		4.install the requirements mentioned in the {requirements.txt} by running command -{pip install -r requirements.txt}
		5.after installation run "gardio.py" file in terminal as {python gardio.py}
